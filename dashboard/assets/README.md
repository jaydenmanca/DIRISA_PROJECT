# Dashboard assets

- `mark.svg` and `empty-state.svg`: original code-drawn assets for this dashboard.
- `hero.webp`: AI-generated, selected from two custom editorial topographic variants and compressed for the Story view. No labels or data are baked into the image.
- `favicon.png`: raster version of the original mark for the browser tab.
- `venue-*.svg`: seven original line icons, one consistent 1.5 px-stroke family.
- `social-preview.png`: 1200×630 share image, composed from the generated hero art with the headline typeset separately in code.

The social preview is ready for use once a hosting platform supports custom Open Graph
metadata. There is no QR image yet because a public dashboard URL has not been supplied.

All colours follow `dashboard/ui/theme.py`. No government or party branding is used.
